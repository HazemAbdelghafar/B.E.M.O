Pros and Cons:

    Tavily:
        -   Requires an API key. (con)
        -   Takes a long time to get a response. (about 40ms if all the types are requested) (about 15-20ms if not all types are requested) (con)
        -   The free tier is not generous enough for the project. (1000 requests per month), the first paid tier is $30 per month for 4000 requests. (con)

        -   The API is very simple to use and reliable. (pro)
    
    Gemini w Tavily:
        -   Requires an API key. (con)
        -   Sometimes labels are not accurate. (con)
        -   Sometimes the API returns an empty response. (con)

        -   Takes no time to get a response. (about 10-15ms) (pro)
        -   The free tier is generous enough for the project. (pro)
